# AI Mental Health Analyzer

## About the Project
AI Mental Health Analyzer is a Python-based web application designed to analyze mental-health-related user input through a simple and user-friendly interface.

## Objectives
- Provide an easy-to-use interface.
- Analyze user-provided information.
- Present analysis results clearly.
- Explore the use of AI in mental health awareness.

## Technologies Used
- Python
- HTML

## Project Structure

AI-MENTAL-HEALTH-ANALYSER/
- app.py
- templates/
  - index.html

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Run the application using:

   python app.py

4. Open the local URL displayed in the terminal.
